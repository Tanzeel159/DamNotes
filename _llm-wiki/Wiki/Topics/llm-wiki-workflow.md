# LLM Wiki Workflow

An LLM Wiki workflow keeps source capture and compiled knowledge separate. Raw sources preserve original context, while Wiki notes hold concise, reusable knowledge derived from those sources.

The recommended query path is to search compiled Wiki notes first, then open Raw sources only when more evidence or detail is needed.
