# Naming Conventions

Use clear, human-readable Markdown filenames.

- Raw source notes: `_llm-wiki/Raw/Sources/descriptive-source-title.md`
- Topic notes: `_llm-wiki/Wiki/Topics/descriptive-topic.md`
- Concept notes: `_llm-wiki/Wiki/Concepts/descriptive-concept.md`
- Entity notes: `_llm-wiki/Wiki/Entities/entity-name.md`
- Project notes: `_llm-wiki/Wiki/Projects/project-name.md`
- Log notes: `_llm-wiki/Wiki/Logs/YYYY-MM-DD-short-title.md`

Prefer lowercase words separated by hyphens for new files. Keep titles in frontmatter or first headings readable and natural.
