# Naming Conventions

Use clear, human-readable Markdown filenames.

- Raw source notes: `Raw/Sources/descriptive-source-title.md`
- Topic notes: `Wiki/Topics/descriptive-topic.md`
- Concept notes: `Wiki/Concepts/descriptive-concept.md`
- Entity notes: `Wiki/Entities/entity-name.md`
- Project notes: `Wiki/Projects/project-name.md`
- Log notes: `Wiki/Logs/YYYY-MM-DD-short-title.md`

Prefer lowercase words separated by hyphens for new files. Keep titles in frontmatter or first headings readable and natural.
