# LLM Wiki Query

Use this skill when answering questions from the LLM Wiki.

1. Start with `Wiki/index.md`.
2. Run `python3 scripts/wiki_tool.py search-catalog --query "question terms"`.
3. Read the most relevant compiled Wiki notes.
4. Open Raw sources only when compiled notes are insufficient or source verification is required.
5. Cite the compiled note and Raw source path for source-backed answers.
